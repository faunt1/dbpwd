## 加密模式对比

| 特性 | ECB模式（传统） | GCM模式（推荐） | 说明 |
|------|---------------|----------------|------|
| **认证加密** | ❌ 否 | ✅ 是 | GCM提供加密+认证双重保护 |
| **防篡改** | ❌ 否 | ✅ 是 | GCM会检测任何密文修改 |
| **IV处理** | 无IV（固定密钥） | 随机IV（12字节） | GCM使用随机防统计分析 |
| **侧信道攻击** | ⚠️ 易受攻击 | ✅ 防护 | GCM的随机IV提供防护 |
| **并行处理** | ❌ 否 | ✅ 支持 | GCM支持并行加解密 |
| **格式** | `ENC(SM4:密文)` | `ENC(SM4-GCM:IV:密文)` | GCM密文包含IV和认证标签 |
| **向后兼容** | N/A | ✅ 支持 | GCM可解密ECB格式 |
| **推荐场景** | 向后兼容 | 新项目/生产环境 | 新项目建议使用GCM |

**推荐**: 新密码使用GCM模式，现有ECB密码可通过 `upgradeToGCM()` 方法升级。

## ECB模式加密流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    SM4密码加密流程（ECB模式）                      │
└─────────────────────────────────────────────────────────────────┘

明文密码 + SM4密钥（16字节，hex编码32字符）
    ↓
┌───────────────────────────────────────────────────────────┐
│ 1. 密钥验证                                               │
│    - 验证密钥格式（32字符hex）                             │
│    - 验证密钥长度（16字节）                                │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 2. SM4加密                                                 │
│    - 加密模式：ECB（电子密码本，无IV）                      │
│    - 输入：明文密码（UTF-8编码）                          │
│    - 填充：PKCS7Padding（自动处理块边界）                  │
│    - 输出：加密后的密文                                    │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 3. Base64编码                                              │
│    - 将二进制密文编码为Base64字符串                       │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 4. 格式化输出                                              │
│    - 格式：ENC(SM4:密文)                                  │
│    - 示例：ENC(SM4:r7X9k3mP8nQ2vL5wY1zA4cD6eF8gH0iJ=)    │
└───────────────────────────────────────────────────────────┘
    ↓
 加密密码（存储到 db.pwd）
```

**注**: ECB模式是传统的SM4加密方式，保持向后兼容性。

## GCM模式加密流程（推荐）

```
┌─────────────────────────────────────────────────────────────────┐
│                  SM4密码加密流程（GCM认证加密模式）                 │
└─────────────────────────────────────────────────────────────────┘

明文密码 + SM4密钥（16字节，hex编码32字符）
    ↓
┌───────────────────────────────────────────────────────────┐
│ 1. 密钥验证                                               │
│    - 验证密钥格式（32字符hex）                             │
│    - 验证密钥长度（16字节）                                │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 2. 生成随机IV（初始化向量）                               │
│    - 使用SecureRandom生成                                │
│    - 长度：12字节（96位，NIST推荐值）                      │
│    - 每次加密使用不同IV，防统计攻击                        │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 3. SM4-GCM认证加密                                        │
│    - 加密模式：GCM（伽罗瓦计数器模式）                     │
│    - 输入：明文密码（UTF-8编码）                          │
│    - 输出：密文 + 认证标签（16字节）                        │
│    - 认证标签：GCM自动生成，用于验证完整性                  │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 4. Base64编码                                              │
│    - IV：12字节 → Base64编码                               │
│    - 密文+标签：可变长度 → Base64编码                       │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 5. 格式化输出                                              │
│    - 格式：ENC(SM4-GCM:Base64(IV):Base64(密文+标签))       │
│    - 示例：ENC(SM4-GCM:AbCdEfGhIjKlMnOp:uVwXyZ...")
└───────────────────────────────────────────────────────────┘
    ↓
 加密密码（存储到 db.pwd）
```

**GCM模式安全优势**:
1. **认证加密**: 同时保护机密性和完整性
2. **防篡改**: 任何对密文的修改都会导致解密失败（认证标签验证失败）
3. **随机IV**: 每次加密结果不同，防止模式分析和侧信道攻击
4. **现代标准**: 符合NIST SP 800-38D和ISO/IEC 19772标准

## 解密流程

### ECB模式解密

```
加密密码（格式：ENC(SM4:密文)）
    ↓
┌───────────────────────────────────────────────────────────┐
│ 1. 格式解析                                               │
│    - 验证格式：ENC(SM4:xxxxxxxx)                          │
│    - 提取算法标识：SM4                                     │
│    - 提取密文：去除ENC(SM4:)前缀                           │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 2. 密钥加载                                               │
│    - 从 ~/.dbpwd/sm4.key 读取密钥                         │
│    - 验证文件权限：600                                     │
│    - 验证密钥格式（32字符hex）                             │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 3. Base64解码                                              │
│    - 将密文字符串解码为二进制                             │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 4. SM4解密                                                 │
│    - 加密模式：ECB                                         │
│    - 输入：Base64解码后的密文                              │
│    - 去除填充：自动处理PKCS7Padding                        │
│    - 输出：明文密码（UTF-8编码）                          │
└───────────────────────────────────────────────────────────┘
    ↓
 明文密码（用于数据库连接）
```

### GCM模式解密

```
加密密码（格式：ENC(SM4-GCM:Base64(IV):Base64(密文+标签))）
    ↓
┌───────────────────────────────────────────────────────────┐
│ 1. 格式解析                                               │
│    - 验证格式：ENC(SM4-GCM:...)                            │
│    - 分解为：IV和密文+标签两部分                            │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 2. 密钥加载                                               │
│    - 从 ~/.dbpwd/sm4.key 读取密钥                         │
│    - 验证文件权限：600                                     │
│    - 验证密钥格式（32字符hex）                             │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 3. Base64解码                                              │
│    - 解码IV：Base64 → 12字节                              │
│    - 解码密文+标签：Base64 → 二进制                        │
└───────────────────────────────────────────────────────────┘
    ↓
┌───────────────────────────────────────────────────────────┐
│ 4. SM4-GCM认证解密                                          │
│    - 加密模式：GCM                                         │
│    - 输入：IV + 密文 + 认证标签                             │
│    - 验证认证标签：自动检查完整性                           │
│    - 输出：明文密码（UTF-8编码）                          │
│    - 注：任何篡改会导致认证标签验证失败                      │
└───────────────────────────────────────────────────────────┘
    ↓
 明文密码（用于数据库连接）
```

## 加密算法参数

### ECB模式参数（旧版）

| 参数 | 值 | 说明 |
|------|-----|------|
| **算法** | SM4 | 国密对称加密算法 |
| **密钥长度** | 128位 | 16字节，hex编码32字符 |
| **块大小** | 128位 | 16字节，SM4标准块大小 |
| **加密模式** | ECB | 电子密码本模式 |
| **填充方式** | PKCS7Padding | 块填充，自动处理边界 |
| **编码方式** | Base64 | 二进制到文本转换 |

### GCM模式参数（新版）

| 参数 | 值 | 说明 |
|------|-----|------|
| **算法** | SM4 | 国密对称加密算法 |
| **密钥长度** | 128位 | 16字节，hex编码32字符 |
| **块大小** | 128位 | 16字节，SM4标准块大小 |
| **加密模式** | GCM | 伽罗瓦计数器模式 |
| **IV长度** | 12字节 | 96位，NIST推荐值 |
| **认证标签长度** | 16字节 | 128位，最大安全级别 |
| **填充方式** | NoPadding | CTR模式不需要填充 |
| **编码方式** | Base64 | 二进制到文本转换 |

## 性能指标

| 操作 | ECB模式 | GCM模式 | 说明 |
|------|---------|---------|------|
| **加密** | < 10ms | < 15ms | GCM略慢但提供认证 |
| **解密** | < 5ms | < 10ms | GCM认证验证 |
| **密钥加载** | < 1ms | < 1ms | 相同 |
| **文件加载** | < 50ms | < 50ms | 相同 |

**性能说明**: GCM模式虽然单次操作略慢ECB（约30-50%），但在安全性上的提升远超性能开销。对于数据库密码管理场景，这些开销完全可以接受。

## 密钥派生算法

### PBKDF2密钥派生（可选增强）

**目的**: 通过密钥派生增强密钥安全性，防止密钥文件泄露后的直接使用风险

**算法**: PBKDF2WithHmacSHA256（基于密码的密钥派生函数2，使用HMAC-SHA256）

### 派生参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **输入密钥** | sm4.key内容 | 从密钥文件读取的hex字符串 |
| **盐值** | 根据环境生成 | 格式：`{app_name}_{env}_{uuid}` |
| **迭代次数** | 10,000 | 密钥派生迭代次数 |
| **输出长度** | 16字节（128位） | SM4密钥长度 |
| **算法标识** | HMAC-SHA256 | 底层哈希算法 |

## 代码示例

### ECB模式加密（向后兼容）

```java
import com.dbpwd.crypto.PasswordEncryptor;
import com.dbpwd.crypto.PasswordDecryptor;

String plainPassword = "MyPassword123";
String sm4Key = "00112233445566778899AABBCCDDEEFF";

// 加密（EB模式）
String encrypted = PasswordEncryptor.encrypt(plainPassword, sm4Key);
// 输出: ENC(SM4:r7X9k3mP8nQ2vL5wY1zA4cD6eF8gH0iJ=)

// 解密
String decrypted = PasswordDecryptor.decrypt(encrypted, sm4Key);
// 输出: MyPassword123
```

### GCM模式加密（推荐）

```java
import com.dbpwd.crypto.PasswordEncryptor;
import com.dbpwd.crypto.PasswordDecryptor;

String plainPassword = "MyPassword123";
String sm4Key = "00112233445566778899AABBCCDDEEFF";

// 加密（GCM模式）- 推荐
String encryptedGCM = PasswordEncryptor.encryptGCM(plainPassword, sm4Key);
// 输出: ENC(SM4-GCM:AbCdEfGhIjKlMnOp:uVwXyZ...)

// 解密
String decrypted = PasswordDecryptor.decrypt(encryptedGCM, sm4Key);
// 输出: MyPassword123
```

### ECB到GCM的升级

```java
import com.dbpwd.crypto.PasswordEncryptor;
import com.dbpwd.crypto.PasswordDecryptor;

String sm4Key = "00112233445566778899AABBCCDDEEFF";

// 原有的ECB加密密码
String ecb = PasswordEncryptor.encrypt("OldPassword", sm4Key);

// 升级到GCM（会保持原始密钥）
String gcm = PasswordEncryptor.upgradeToGCM(ecb, sm4Key);

// 使用GCM格式的密码
String decrypted = PasswordDecryptor.decrypt(gcm, sm4Key);
```

### 支持ECB和GCM混合格式

```java
import com.dbpwd.crypto.PasswordDecryptor;

String sm4Key = "00112233445566778899AABBCCDDEEFF";

// ECB格式的密码
String ecbPassword = "ENC(SM4:r7X9k3m...)";

// GCM格式的密码
String gcmPassword = "ENC(SM4-GCM:AbCdEf...)";

// 明文密码
String plainPassword = "MyPassword";

// 都能正确解密
PasswordDecryptor.decrypt(ecbPassword, sm4Key);      // ECB解密
PasswordDecryptor.decrypt(gcmPassword, sm4Key);      // GCM解密
PasswordDecryptor.autoDecrypt(plainPassword, sm4Key); // 识别明文
```

## API参考

### PasswordEncryptor

```java
// ECB加密（向后兼容）
String encrypt(String plainPassword, String sm4Key)

// GCM加密（推荐）
String encryptGCM(String plainPassword, String sm4Key)

// ECB到GCM升级
String upgradeToGCM(String ecbEncryptedPassword, String sm4Key)

// 检查加密状态
boolean isEncrypted(String password)
```

### PasswordDecryptor

```java
// 自动解密（识别格式）
String autoDecrypt(String password, String sm4Key)

// 显式解密
String decrypt(String encryptedPassword, String sm4Key)
```

```java
// GCM加密
String encrypt(String plainText, String hexKey)

// GCM解密
String decrypt(String cipherText, String hexKey)

// 密钥验证
boolean isValidKey(String hexKey)

// 生成密钥
String generateRandomHexKey()

// 获取参数
int getKeyLength()     // 16
int getIvLength()       // 12
int getTagLength()     // 16
String getTransformation() // "SM4/GCM/NoPadding"
```

## 安全最佳实践

1. **新项目使用GCM**: 新密码文件中的密码应使用 GCM 模式加密
2. **升级现有密码**: 使用 `upgradeToGCM()` 方法将现有 ECB 密码升级到 GCM
3. **保持密钥安全**: 确保 `sm4.key` 文件权限为 600，存储在安全位置
4. **定期密钥轮换**: 建议每年至少轮换一次密钥
5. **审计日志**: 记录所有密码解密操作
