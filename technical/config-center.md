# 配置中心集成

> 文档版本: v3.0
> 最后更新: 2026-02-08

## 配置中心目录结构

配置中心按物理组/应用/环境三层目录结构保存文件：

```
/databases/
├── 物理组A/                       # 物理组织分组
│   └── 财务系统/                   # 系统名称
│       └── 应用名称/                  # 应用名称
│           ├── prod/                  # 生产环境
│           │   ├── db.pwd            # 密码文件
│           │   └── sm4.key           # SM4密钥文件
│           ├── test/                  # 测试环境
│           │   ├── db.pwd
│           │   └── sm4.key
│           ├── dev/                   # 开发环境
│           │   ├── db.pwd
│           │   └── sm4.key
│           └── uat/                   # UAT环境
│               ├── db.pwd
│               └── sm4.key
├── 物理组B/
│   └── 支付系统/
│       └── 支付应用/
│           ├── prod/
│           │   ├── db.pwd
│           │   └── sm4.key
│           └── test/
│               ├── db.pwd
│               └── sm4.key
```

## 完整路径示例

```
/path: /物理组-财务系统/支付应用/prod/db.pwd
/path: /物理组-财务系统/支付应用/test/sm4.key
/path: /支付中心/订单服务/uat/db.pwd
```

## 配置中心配置

```yaml
# 配置中心配置
config-center:
  url: http://config-center.example.com
  api-key: your-api-token
  environment: ${APP_ENV:prod}      # 应用环境标识
  base-path: /databases            # 配置中心基础路径
```

## 配置下载流程（独立同步工具）

同步工具独立运行，拉取配置中心文件到本地：

```
┌─────────────────────────────────────────────────────────────┐
│                    同步工具 (Sync Tool)                      │
│  （独立进程，定时任务或手动触发）                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ↓
1. 从配置中心获取当前环境的文件（根据environment参数）
   ↓
2. 对比本地文件更新时间（lastModified字段）
   - 如果本地文件不存在或配置中心更新时间更新：下载文件
   - 如果本地文件更新时间较新：跳过下载，记录警告
   ↓
3. 验证下载文件的完整性，设置为600权限
   ↓
4. 原子性替换本地文件
   ↓
5. 记录同步审计日志

┌─────────────────────────────────────────────────────────────┐
│                   应用程序 (Application)                     │
│  （启动时只读取本地文件，与配置中心完全解耦）                  │
└─────────────────────────────────────────────────────────────┘
                            │
                            ↓
应用启动
   ↓
1. 验证本地文件存在和权限（600）
   ↓
2. 加载密码文件（JSON格式）
   ↓
3. 加载密钥文件（sm4.key）
   ↓
4. 初始化密码服务
   ↓
5. 连接池使用密码服务获取数据库密码
```

## 本地文件路径

配置中心文件下载到本地固定路径：

```
~/.dbpwd/
├── db.pwd          # 密码文件（权限600）
└── sm4.key         # SM4密钥文件（权限600）
```

## 评审管理流程

每个环境独立的评审管理流程：

```
1. 系统经理/安全管理员发起密码或密钥更新请求
   ↓
2. 进入配置中心的审批流程
   - 生产环境：需要多层级审批（部门主管→安全管理员→平台审批）
   - 测试环境：需要部门主管审批
   - 开发环境：自动审批或快速审批
   ↓
3. 审批通过后，文件上传到配置中心（自动设置文件权限600）
   ↓
4. 配置中心记录更新时间和审计日志
   ↓
5. 应用下次启动或定时同步时下载最新文件
```

## 文件同步策略

| 策略 | 描述 | 优势 |
|------|------|------|
| 手动触发 | 通过API手动上传下载 | 精确控制 |
| 定时刷新 | 定期检查配置中心更新 | 自动化 |
| Webhook | 配置中心变更时推送 | 实效性好 |
