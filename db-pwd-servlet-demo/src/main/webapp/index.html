Database Password Manager - Servlet Demo

集成模块: db-pwd-web (方案6: Servlet InitListener集成)

功能演示: REST API服务、ENC(SM4-GCM)密码解密、H2内存数据库

API接口

  • GET /api/users - 获取所有用户
  • GET /api/users/{id} - 获取指定ID的用户
  • POST /api/users - 创建新用户
  • PUT /api/users/{id} - 更新用户
  • DELETE /api/users/{id} - 删除用户

测试命令

# 获取所有用户
curl http://localhost:8081/dbpwd-servlet-demo/api/users

# 获取指定ID的用户
curl http://localhost:8081/dbpwd-servlet-demo/api/users/1

# 创建用户
curl -X POST http://localhost:8081/dbpwd-servlet-demo/api/users \
  -H "Content-Type: application/json" \
  -d '{"username":"test_user","email":"test@example.com","password":"password123"}'

返回格式

{ "success": true, "data": [ { "id": 1, "username": "john_doe", "email": "john@example.com", "password": "***", "status": 1 } ] }

技术特点

  • ENC(SM4-GCM:xxx)格式密码自动解密
  • ServletContextListener初始化密码管理服务
  • 纯Servlet API，不依赖Spring
  • Druid连接池管理数据库连接
  • H2内存数据库（无需外部数据库）
